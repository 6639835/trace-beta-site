App review information

Overview

Trace is a developer tool for capturing and debugging network traffic that the user is authorized to inspect, with an API request workbench (Compose). Capture is explicitly enabled by the user. iOS supports Proxy and Tunnel capture; macOS uses a transparent proxy. Optional paired-Mac features can transfer captured traffic to a Mac selected by the user and route origin connections through that Mac.

No Account Required

Trace does not require an app account or demo login. Authenticated API requests require the user's API credentials.

How To Exercise The Main Features During Review

1. Capture: On iOS, choose Settings > Capture Mode > Tunnel, then start capture from the Capture tab and approve the VPN configuration. On macOS, choose Start Capture and approve the NetworkExtension configuration when prompted. Browse a website or use another app to generate traffic, then inspect requests and responses.

2. HTTPS: Stop capture before changing decryption settings. Open Certificate & Trust. On iOS, choose Open Install Page, install the downloaded profile in Settings, then enable full trust in Settings > General > About > Certificate Trust Settings. On macOS, choose Install Trace CA and confirm the trust operation; macOS may request authentication. Enable HTTPS decryption in capture settings, start capture, and generate HTTPS traffic.

3. Compose: Open Compose, create a GET request to a public API, send it, and inspect the response, headers, timing, and tests.

4. Import/Export: Import a cURL command or HAR file, or export a capture as HAR. Insomnia is supported for import; collection exports include Trace, Postman, OpenAPI, and Markdown.

5. Optional paired-Mac capture: On macOS, open Settings > Device Capture, enable Allow Device Capture, and choose Pair New Device. On iOS, open Settings > Mac Connection > Add Mac and complete pairing. Choose the Mac under Mac Display to sync captures. Internet Exit is selected separately; routing through the Mac also requires Allow Devices to Use This Mac's Internet on the Mac. This is not required for standalone capture or Compose.

Networkextension Usage

  • iOS Tunnel capture uses a Packet Tunnel that the user explicitly enables. macOS capture uses a transparent proxy provider that also requires user approval.
  • These are capture extensions, not a developer-operated remote VPN service. iOS Tunnel supports direct connections or an unauthenticated HTTP upstream proxy. Other proxy paths support HTTP/SOCKS5 upstreams. A paired Mac can also be selected as Internet Exit.

Certificate / Mitm Disclosure

HTTPS inspection uses a locally generated CA. iOS installation and full trust require manual action in Settings. macOS provides an explicit, confirmed install-and-trust action. Without trust or with decryption disabled, HTTPS is forwarded encrypted. Capture and decryption remain subject to the configured routing and filtering settings.

Data Handling

Capture and Compose data are persisted locally. If Mac Display sync is enabled, captured traffic is also transferred to the selected paired Mac. Internet Exit routing is independent of display sync. Enabled Report Server rules send matching captures to a configured URL. Trace does not automatically upload captures to developer-operated servers.

CA private keys, variables marked secret, and supported authentication secrets use Keychain. Compose workspace exports scrub designated secrets and authentication fields; captured traffic and HAR exports can contain sensitive URLs, headers, cookies, tokens, and bodies.

Permissions Used And Why

  • NetworkExtension: iOS Packet Tunnel and macOS transparent capture.
  • Local network: discover, pair, and connect to a Mac or receive captures from paired devices. Local proxy and certificate-download endpoints are also used by the app.
  • Keychain: CA private keys, Compose secrets, and paired-device credentials.
